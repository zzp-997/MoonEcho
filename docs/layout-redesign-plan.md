# 回声 App 排版重构计划

> 创建时间：2026-05-08
> 状态：进行中
> 目标：从"换皮不换骨"升级到结构化排版，每屏有独立的布局策略

---

## 重构原则

1. **每屏有自己的布局策略**，不再所有页面同构
2. **用空间分组代替卡片堆叠**，减少不必要的容器
3. **间距有节奏**：组内紧凑（8-12px），组间留白（24-48px）
4. **层级靠空间+字重**，不只靠颜色
5. **遵循 DESIGN.md**：小圆角(4-6px)、边框层级、无阴影

```
├─────────────────────────┤
│                         │

│ │ [温] 小温    对话 →  │ │ ← AI入口（卡片2）
│ │      想聊聊吗        │ │   与情绪条视觉同级
│ └─────────────────────┘ │
│ ┌─────────────────────┐ │
```

### 排版方案

**布局策略**：分层递进 — 问候语建立情感锚点，情绪状态紧随其下形成"我的状态"分组，AI入口作为独立行动区块用空间分隔，快捷入口去卡片化用网格排列，动态流用分割线分组。

```
┌─────────────────────────┐
│ 回声            🔔      │ ← 导航栏：品牌名 + 通知
├─────────────────────────┤
│                         │
│ 夜深了，                │ ← 问候语：大字号(24px)
│ 今天还好吗              │    两行断句，有呼吸感
│                         │ ← 组间留白 32px
│ ┌─ 我的状态 ────────────┐│
│ │ ● 今天感觉怎么样      ││ ← 情绪条：无卡片
│ │   写点什么吧     记录→││    与问候语同组
│ └──────────────────────┘│
│                         │ ← 组间留白 24px
│ ┌─────────────────────┐ │
│ │ [温] 小温            │ │ ← AI入口：唯一卡片
│ │      想聊聊吗   对话→│ │    视觉权重最高
│ └─────────────────────┘ │    代表核心功能
│                         │ ← 组间留白 24px
│  📅记日记  🕳️树洞      │ ← 快捷入口：去卡片化
│  ⭐广场    📊周报       │    2×2网格，无背景
│                         │ ← 组间留白 32px
│ 近期动态               │ ← 次级区块标签
│ ───────────────────── │    小号大写字母间距
│ 匿名  内容预览     3分前 │
│ ───────────────────── │    分割线分组
│ 匿名  内容预览     1小时 │
│                         │
└─────────────────────────┘
```

### 关键排版决策

| 决策 | 之前 | 之后 | 原因 |
|------|------|------|------|
| 问候语断行 | 一行完整 | 两行断句 | 增加视觉重量，建立情感锚点 |
| 情绪条容器 | bg-secondary 卡片 | 去卡片，与问候语同组 | 情绪状态是问候的延伸，不是独立模块 |
| AI入口容器 | 与其他卡片同级 | 唯一突出卡片 | AI对话是核心差异点，值得视觉强调 |
| 快捷入口容器 | bg-secondary 卡片 | 去卡片，2×2网格 | 四个等权入口不需要容器分隔 |
| 间距节奏 | 全部 md(16px) | 组内8-12px，组间24-32px | 有节奏的空间创造层级 |
| 动态列表分割 | border-bottom | 分割线 + 小号标签 | 与"近期动态"形成清晰的次级区块感 |

```
├─────────────────────────┤
│ ┌─────────────────────┐ │
│ │ 记一笔今天的感受? → │ │ ← 快速记录（卡片1）
│ └─────────────────────┘ │
│ ┌─────────────────────┐ │
│ │ 本周情绪报告    →   │ │ ← 周报入口（卡片2）
│ │ 洞察文字...         │ │   与快速记录视觉同级
│ │ [关键词] [关键词]   │ │
│ └─────────────────────┘ │
│ ┌─────────────────────┐ │
│ │  12   │   8  │  3   │ │ ← 统计区（卡片3）
│ │ 总记录│ 记录天│ 连续 │ │   hero-metric 倾向
│ └─────────────────────┘ │
│ ┌───┐ ┌───┐ ┌───┐     │ ← Tab切换
│ │日历│ │图表│ │列表│     │   bg-secondary + brand-primary
│ └───┘ └───┘ └───┘     │   风格与克制调性冲突
│                         │

│                         │
└─────────────────────────┘

问题：三卡片同构堆叠、统计区 hero-metric、Tab 风格太重
```

### 排版方案

**布局策略**：引导优先 — 快速记录是页面的行动锚点，给予最大空间和视觉权重；周报和统计是辅助信息，去卡片化用空间分组；Tab 用下划线风格融入克制调性。

```
┌─────────────────────────┐
│ 情绪日记         ⬇️     │ ← 导航栏
├─────────────────────────┤
│                         │
│ 记一笔今天的感受?        │ ← 快速记录：无卡片
│                         │    大字号行动引导
│ [暖] [平] [低] [伤] [乱]│ ← 情绪色调快捷选择
│                         │    直接在记录区下方
│                         │ ← 组间留白 32px
│ 本周情绪报告             │ ← 周报入口：去卡片
│ "这周像一场漫长的周三"   │    引用格式突出洞察
│ [焦虑] [疲惫] [迷茫]    │    关键词标签
│                     查看→│
│                         │ ← 组间留白 24px
│   12       8       3    │ ← 统计：去卡片
│ 总记录   记录天   连续天 │    小字号，低调存在
│                         │ ← 组间留白 24px
│  日历    图表    列表    │ ← Tab：下划线风格
│ ─────                   │    选中项底部细线
│                         │    不用填充背景
│ [日历组件]              │
│                         │
└─────────────────────────┘
```

### 关键排版决策

| 决策 | 之前 | 之后 | 原因 |
|------|------|------|------|
| 快速记录 | 卡片+箭头 | 去卡片，直接文字引导 | 行动号召不需要容器 |
| 情绪色调 | 无 | 在记录引导下直接展示5色 | 降低操作路径，符合PRD"轻引导"原则 |
| 周报入口 | 独立卡片 | 去卡片，引用格式 | 洞察内容本身有价值，不需要装饰 |
| 统计区 | 居中大数字卡片 | 左对齐小字号 | 避免hero-metric，统计是辅助信息 |
| Tab切换 | 填充背景+品牌色 | 下划线风格 | 更克制，符合DESIGN.md调性 |

## 通用排版改进

以下改进适用于所有页面，不需逐屏规划：

| 改进 | 说明 |
|------|------|
| 去掉三层阴影 | 统一改为 1px border 或无边框 |
| 统一导航栏 | 品牌名/页面标题 + 右侧操作，底部 1px 边框 |
| 统一TabBar | 图标+文字，当前项微妙变化，顶部 1px 边框 |
| 空状态 | 从居中两行文字 → 有引导行动的空状态 |
| 分割线 | 统一用 border-light 色值，1px |
| 去掉rpx混用 | 统一用 px 或 CSS 变量 |
