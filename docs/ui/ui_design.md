## 一、设计风格定义

### 1.1 整体视觉风格

**设计理念**：深夜情绪容器 — 温暖、安全、私密、不评判

回声的核心使用场景是深夜，用户情绪脆弱、需要宣泄。视觉设计必须：
- 降低视觉刺激（暗色系减少眼睛疲劳）
- 传递安全感和温度（不是冰冷的工具感）
- 营造私密氛围（像深夜和一个信任的人对话）
- 不增加认知负担（简洁、无干扰）

**风格关键词**：
- 暗色系主调（适合深夜使用）
- 柔和圆润（降低攻击性）
- 微光感（深夜窗口的意象）
- 呼吸感（留白充足，不压迫）

**设计参考风格**：
- 类似Notion、Bear的文档类暗色界面（静谧、专注）
- 类似Calm、Headspace的情绪类APP（温暖、安全）
- 类似Telegram Night模式的聊天界面（清晰、护眼）

### 1.2 色彩系统

#### 1.2.1 情绪色调（品牌核心）

这五种颜色是产品的灵魂，贯穿整个视觉系统：

| 色调名称 | 色值 | 含义 | 使用场景 |
|---------|------|------|---------|
| 暖橘 | #FF9A5C | 充满能量、开心 | 正向情绪记录、开心动态标识 |
| 浅绿 | #8FCCA0 | 平静、安稳 | 中性情绪、稳定状态 |
| 灰蓝 | #8BA7C4 | 低落、沉闷 | 略显低落的情绪 |
| 深蓝 | #4A6FA5 | 难过、忧伤 | 明显负面情绪 |
| 暗紫 | #6B4C7A | 崩溃、混乱 | 无法名状的复杂情绪 |

**情绪色调应用原则**：
- 每种颜色都有独立语义，不能混用
- 情绪色用于标识、强调，不作为大面积背景
- 同一页面情绪色调不宜超过2种

| AI角色 | 色值 | 含义联想 |
|--------|------|---------|
| 小温 | #FFB5BA | 温暖粉色（温柔姐姐感） |

#### 1.2.4 色彩可访问性

**对比度要求**：
- 主文字与背景：对比比 >= 7:1（WCAG AAA）
- 次文字与背景：对比比 >= 4.5:1（WCAG AA）
- 功能性元素：可适当降低但保持可识别

**色盲友好**：
- 情绪色调不只依赖颜色区分，同时配图标/文字
- 重要信息不只用颜色表达

### 1.4 间距系统

采用 **8px 基准网格系统**，所有间距为8的倍数：

| Token | 值 | 用途 |
|-------|-----|------|
| --space-4xs | 2px | 极小间距（图标与文字） |
| --space-3xs | 4px | 按钮内图标间距 |
| --space-2xs | 8px | 紧凑元素间距 |
| --space-xs | 12px | 小元素间距 |
| --space-sm | 16px | 标准内边距 |
| --space-md | 24px | 区块间距 |
| --space-lg | 32px | 大区块间距 |
| --space-xl | 48px | 页面级间距 |
| --space-2xl | 64px | 特大间距 |

**应用规则**：
- 页面左右边距：16px（--space-sm）
- 卡片内边距：16px（--space-sm）
- 列表项间距：12px（--space-xs）
- 输入框内边距：12px（--space-xs）

## 十、危机干预弹窗设计（P0-U1）

### 10.1 三层危机干预体系

根据用户情绪监测和对话内容分析，系统设置三层危机干预机制，层层递进：

| 层级 | 触发条件 | 弹窗形式 | 核心元素 |
|------|---------|---------|---------|
| 第一层 | 情绪低落信号 | 底部半屏卡片 | AI角色化关怀，无热线 |
| 第二层 | 自残意念信号 | 底部半屏卡片 | 热线电话+AI陪伴，双按钮 |
| 第三层 | 紧急信号 | 全屏模态弹窗 | 大字热线+一键拨打，无忽略 |

### 10.2 第一层：情绪低落干预

| 手动覆盖 | 用户手动选择主题后，自动切换暂停，直到用户重新开启开关 |
| 与"跟随系统"互斥 | 选择"跟随系统"时，夜间自动切换开关置灰不可用 |
| 与"暗色模式"互斥 | 选择"暗色模式"时，夜间自动切换开关置灰不可用（已始终暗色） |
| 亮色模式下生效 | 仅在"亮色模式"或"夜间自动切换"选中时，开关可操作 |

**夜间自动切换状态机**：

```
用户选择"亮色模式" + 开启"夜间自动切换":
  白天 (06:00-21:59) -> 亮色模式
  夜间 (22:00-05:59) -> 暗色模式

用户选择"暗色模式":
  始终暗色（夜间自动切换置灰）

用户选择"跟随系统":
  跟随系统主题（夜间自动切换置灰）
```

### 20.1 P2-21：情绪色调在树洞/广场卡片中贯穿使用
