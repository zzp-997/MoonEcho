# 回声 APP - Android APK 构建指南

> 文档版本：v1.0
> 创建日期：2026-05-03
> 适用阶段：公测版（100-200人）
> 打包方式：HBuilderX 云打包

## 一、前置准备

### 1.1 环境要求

| 项目 | 要求 |
|------|------|
| HBuilderX | v3.8.0+（推荐最新稳定版） |
| DCloud 账号 | 已注册并登录（云打包需要） |
| 项目 | `frontend/` 目录已用 HBuilderX 打开 |
| manifest.json | 已完成 app-plus 配置 |

### 1.2 manifest.json 配置检查

在打包前确认以下配置已就绪：

```json
{
  "versionName": "1.0.0-beta",
  "versionCode": "100",
  "app-plus": {
    "distribute": {
      "android": {
        "packagename": "com.huisheng.app",
        "targetSdkVersion": 33,
        "minSdkVersion": 21,
        "abiFilters": ["armeabi-v7a", "arm64-v8a"]
      }
    }
  }
}
```

## 二、证书配置

### 2.1 公测版：使用测试证书（Debug 签名）

公测阶段建议使用 HBuilderX 提供的**公共测试证书**，无需自行生成。

优势：
- 无需配置 Android SDK 和 JDK 环境
- 一键云打包，快速出包
- 适合 100-200 人小规模分发

限制：
- 证书为公共测试证书，无法上架 Google Play
- 签名不唯一，不适合正式发布

### 2.2 正式版：自有证书（后续阶段使用）

如需自有证书，按以下步骤生成：

```bash
# 生成密钥库（需要 JDK 环境）
keytool -genkey -v -keystore huisheng-release.keystore \
  -alias huisheng \
  -keyalg RSA \
  -keysize 2048 \
  -validity 10000 \
  -storepass YOUR_STORE_PASSWORD \
  -keypass YOUR_KEY_PASSWORD

# 查看证书信息
keytool -list -v -keystore huisheng-release.keystore
```

证书信息记录表：

| 字段 | 值 |
|------|----|
| 密钥库文件 | huisheng-release.keystore |
| 别名 (alias) | huisheng |
| 密钥库密码 | 记录在安全位置 |
| 密钥密码 | 记录在安全位置 |
| 有效期 | 10000天（约27年） |

## 三、HBuilderX 云打包步骤

### 3.1 打开项目

1. 启动 HBuilderX
2. 文件 → 打开目录 → 选择 `MoonEcho/frontend/`
3. 等待项目加载完成，确认无编译错误

### 3.2 配置打包参数

1. 在项目根目录找到 `manifest.json`
2. 点击打开，进入**可视化配置界面**
3. 确认以下配置项：

**基础配置**：
- 应用名称：回声
- 应用版本名：1.0.0-beta
- 应用版本号：100

**App 图标配置**：
- 点击"App图标配置"
- 上传 1024x1024 的应用图标
- 点击"自动生成所有图标"

**App 启动界面**：
- 选择"自定义启动界面"
- 上传启动页图片（建议 1080x1920）
- 或使用默认启动界面

**App 模块配置**：
- Push（推送）：勾选，配置极光推送
- Camera（相机）：勾选
- Storage（存储）：勾选
- Contacts（通讯录）：按需勾选

### 3.3 执行云打包

1. 菜单栏 → **发行** → **原生App-云打包**
2. 弹出打包配置窗口，选择以下参数：

| 参数 | 公测版选择 | 说明 |
|------|----------|------|
| 打包类型 | 使用公共测试证书 | 公测阶段使用 |
| Android | 勾选 | 打包 Android APK |
| iOS | 不勾选（需要开发者账号） | 公测阶段先不打包 iOS |
| 打包方式 | 正式包 | 非调试包 |
| 使用原生壳 | 标准 | 使用标准基座 |

3. 点击**打包**按钮
4. 等待云端编译（通常 3-10 分钟）
5. 打包完成后，APK 文件自动下载到本地

### 3.4 输出文件位置

打包成功后，APK 文件位置：
- Windows: `HBuilderX安装目录\unpackage\apk\`
- 文件名格式：`huisheng__1.0.0-beta.apk`

将 APK 复制到项目分发目录：
```bash
cp ~/unpackage/apk/huisheng__1.0.0-beta.apk dist/beta/huisheng-1.0.0-beta.apk
```

## 四、打包后验证

### 4.1 安装验证

| 测试项 | 验证方法 | 预期结果 |
|--------|---------|---------|
| 安装 | 在 Android 手机安装 APK | 安装成功，图标显示正确 |
| 启动 | 点击应用图标 | 启动页正常，进入首页 |
| 登录 | 手机号 + 验证码登录 | 登录成功，跳转首页 |
| AI 对话 | 发送消息 | SSE 流式响应正常 |
| 情绪日记 | 记录情绪 | 保存成功 |
| 树洞 | 发布吐槽 | 匿名发布成功 |
| 推送 | 接收通知 | 通知到达 |
| 相机 | 拍照上传 | 权限申请正常 |
| 存储 | 保存图片 | 写入成功 |

### 4.2 兼容性测试

| 测试机型 | Android 版本 | 安装 | 运行 | 核心功能 |
|---------|-------------|------|------|---------|
| 小米 13 | 13 | - | - | - |
| 华为 P60 | 12 | - | - | - |
| OPPO Find X5 | 12 | - | - | - |
| 三星 S23 | 13 | - | - | - |
| 红米 Note 12 | 12 | - | - | - |

### 4.3 常见问题排查

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 安装失败 - 解析包错误 | APK 损坏或签名异常 | 重新云打包 |
| 安装失败 - 空间不足 | 手机存储空间不够 | 清理手机空间 |
| 启动白屏 | 网络连接问题或 API 不可达 | 检查网络和后端服务 |
| 权限被拒绝 | Android 13+ 需动态申请 | 检查运行时权限逻辑 |
| 推送收不到 | 极光配置未生效 | 检查极光 AppKey 和包名 |

| 版本类型 | versionName | versionCode | 说明 |
|---------|------------|------------|------|
| 公测版 | 1.0.0-beta | 100 | 首个公测版 |

### 5.2 每次打包前检查清单

- [ ] 更新 `manifest.json` 中的 versionName 和 versionCode
- [ ] 确认后端 API 地址正确（.env.beta）
- [ ] 运行前端类型检查：`npm run type-check`
- [ ] 在浏览器中测试 H5 版本功能正常
- [ ] 确认无 console.log 等调试代码残留
- [ ] 执行云打包
